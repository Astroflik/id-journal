## Архитектура сцены журнала (фаза 1, кратко)
- **Мир** — один слой `#world` с CSS 3D (`perspective` на корне). У каждой вкладки своя **станция**: фиксированная точка мира `{x, y, z, ry}` в одном конфиге.
- **Камера** — одно состояние `{x, y, z, ry}`; мир получает обратное преобразование. Полёт к вкладке — прямая (с лёгкой дугой) от текущей точки к целевой, длительность по расстоянию, промежуточные станции не останавливают полёт и не активируются.
- **Читаемость** — активная станция в конце полёта стоит ровно в плоскости экрана (масштаб 1, без поворота), текст и поля ввода остаются обычным DOM: без размытия, фокус и клики работают. Виджеты внутри станции смещены по Z в небольших пределах.
- **Фон** — лёгкий слой точек/изолиний (canvas), выключается в режиме производительности и без WebGL; без него журнал полностью работает.
- **Неактивные станции** — скрыты от рендера и ввода (`visibility`, `inert`, `content-visibility`), их анимации на паузе; во время полёта видны как силуэты.
- **Один владелец `transform`**: камера двигает только `#world`; станция имеет только свой статичный `transform`; виджет — только контроллер появления/дыхания. `fly.js` в журнале отключается (конфликт со сценой).
- **Доступность**: `prefers-reduced-motion` и режим «Движение: выключено» — вместо полёта короткая смена кадра; клавиатура (Tab, стрелки по панели вкладок), `aria-current`.
