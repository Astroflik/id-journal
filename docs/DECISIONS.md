- 2026-11-11 · Глубина виджетов: только на время полёта (`#v.flying` с `preserve-3d`, дети `#v` получают `translate: 0 0 Z`, Z = `--wk` × слой). В покое глубины нет — текст остаётся чётким. Прозрачность на время полёта идёт детям (`--wo`), потому что `opacity` на контейнере «сплющила» бы 3D. · Раньше все виджеты лежали в одной плоскости.
- 2026-11-11 · Кнопка брифинга — в общем ряду быстрых кнопок (`.quick-actions`), а не отдельным плавающим кружком слева: так она не может наложиться на панель вкладок при любой стороне. Пока открыт брифинг, ряд поднят над ним. · Тест «кнопки не перекрывают панель на четырёх краях».
- 2026-11-11 · Кнопка «Анимации» в ряду и список «Движение интерфейса» в форме оформления остаются обе: они меняют одну и ту же настройку (быстрое вкл/выкл и три уровня). Объединю с режимом производительности в фазе 4.
- 2026-11-11 · Значки вкладок и кнопок уже рисованные SVG (`iconify` заменяет эмодзи); проверка DOM по всем вкладкам нашла один эмодзи (📰) — заменён.
- 2026-11-11 · Старые функции переходов (`go0`, `goCine`, `goVT`, `goRing`) мертвы — их заменил полёт камеры. Удаляю в фазе 8 (длинные строки app.js, риск при правке вслепую).
- 2026-11-11 · Анимации фазы 3 разведены по времени, чтобы у свойства всегда был один владелец: полёт — камера (`transform` у `#v`, глубина `translate` у детей); покой — появление (`wIn`) и «дыхание» (`breathe`, только плитки). `#v.flying` выключает обе. · Иначе CSS-анимация перекрывает `translate` глубины.
- 2026-11-11 · Появление виджетов — только при первом показе вкладки без полёта (открытие журнала, конец интро). Вкладку, куда прилетела камера, вносит сама глубина; второе появление было бы лишним. · Меньше движения, один «момент» вместо двух.
- 2026-11-11 · «Дыхание» — только плитки статистики и только при «Движение: полное». Карточки с полями ввода не двигаются: дрейф под курсором мешает печатать. · Режим «лёгкое» (по умолчанию) остаётся спокойным.
- 2026-11-11 · Линии графиков рисуются один раз при приходе на вкладку; при обычной перерисовке (ввод, фильтры) сразу видны целиком. · Раньше линия стиралась и рисовалась заново при каждом `render()`.
- 2026-11-11 · Режим производительности: «авто» включается при ≤2 ядрах / ≤2 ГБ памяти / saveData или если при старте >40 из 90 кадров медленнее 40 мс; выбор владельца («включён/выключен») всегда сильнее авто. Кнопка «Анимации» и «Движение» остаются отдельной осью (что двигается), производительность — что рисуется. · Задание п. про режим производительности.
